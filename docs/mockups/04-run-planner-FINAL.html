Query preview

Each stop shows the exact Google Maps search it will run. A wrong qualifier — the "Thika Nairobi" class of bug — becomes visible before you spend 4 minutes of worker time on it.

Area list, tiers and county assignments read from scraper/spiders/apartments.py. Durations use the verified ~253s per apartments location and an estimated ~110s for agencies (2 searches vs 7) against the 720s subprocess ceiling. County list is the 47 constitutional counties; areas outside the bundled set are shown as an honest empty state.
