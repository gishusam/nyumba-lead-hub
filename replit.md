# Nyumba Zetu

A lead intelligence platform for Nairobi's property market. Helps sales teams identify, prioritize, and convert apartments, agencies, and landlords from one workspace.

## Stack

- **Framework**: TanStack Start (SSR React) with TanStack Router (file-based routing)
- **UI**: shadcn/ui components, Tailwind CSS v4
- **Package manager**: Bun
- **Build tool**: Vite (via `@lovable.dev/vite-tanstack-config`)
- **Language**: TypeScript

## Running the app

```bash
bun run dev
```

Starts the dev server on port 5000. The workflow "Start application" is configured to do this automatically.

## Project structure

- `src/routes/` — File-based routes (TanStack Router). Do **not** create `src/pages/` or `app/layout.tsx`.
- `src/components/` — Shared UI components
- `src/lib/` — Utilities and API helpers
- `src/data/` — Static/mock data
- `src/hooks/` — Custom React hooks
- `src/styles.css` — Global styles
- `routeTree.gen.ts` — Auto-generated by TanStack Router; do not edit manually

## Notes

- Auth is token-based; `getToken()` from `src/lib/api` drives the auth guard in `_app.tsx`.
- The Lovable vite config forces port 8080 inside the Lovable sandbox; on Replit the `vite.server` override in `vite.config.ts` sets port 5000 correctly.
